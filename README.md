# 斩杀线 (Kill Line)

一款 H5 剧情互动游戏 - 结构性不平等、心理博弈、社会学隐喻

## 核心命题

**"人并不是因为错误而被淘汰，而是因为在某个结构中承担了不被允许的风险。"**

这不是关于努力是否成功、道德是否高尚，而是关于：
- 结构如何分配风险
- 不同出生的人，被允许靠近斩杀线的距离本就不同
- 不公平，但合理；不残酷，但真实

## 世界观

这个世界并不宣告善恶，它只记录风险。

每个人出生时，都被赋予一条不可见的线。线不会移动，但你会靠近它。当你越过那条线，世界不会审判你，它只是不再允许你继续存在于当前叙事中。

## 核心机制

### 身份系统（起点偏置）

身份不是皮肤，而是隐形参数集。每个身份有不同的：
- 风险敏感度（同样行为，承担的风险不同）
- 容忍度（越线的缓冲空间）
- 可见度（被注意的概率）
- 资源衰减速度
- 意义资源获取效率

**3 个身份原型：**

| 身份 | 特点 | 隐含叙事 |
|------|------|----------|
| 本地稳定阶层 | 低风险敏感度，高容忍度 | 更不容易越线，但关系更工具化 |
| 流动/边缘阶层 | 高风险敏感度，低容忍度 | 任何举动都更容易越线，但关系更真实 |
| 优势/稀缺阶层 | 中等风险，高可见度 | 生存资源强，但行为高度显性 |

### 双重资源轴

游戏有两条互相拉扯的轴：

**轴一：生存资源（外在）**
- 金钱、地位、系统认可度
- 作用：延缓斩杀、打开更多选项、增加容错

**轴二：意义资源（内在）**
- 亲情、友情、自我一致性、被理解感
- 作用：提高生存质量、影响结局文本

⚠️ **核心冲突**：两条轴不会同时满
- 越安全，越空洞
- 越真实，越危险

### 数值系统

```typescript
risk = 0              // 风险值
survival = 2          // 生存资源
meaning = 3           // 意义资源
KILL_LINE = 10        // 基础斩杀线

// 实际风险 = 行为风险 × 身份敏感度
// 斩杀线 = 基础斩杀线 + 身份容忍度
```

### 多周目记忆系统

- 系统会记录你的选择倾向（风险规避者、关系牺牲者、越界者等）
- 二周目开始，某些文本会变化，某些选项会提前消失
- 记忆标记影响叙事，但不改变核心机制

## 结局系统（双轴评估）

结局不是好坏，而是「存活方式报告」

### 评估维度

**生存时间（横轴）**
- 短暂：提前越线
- 普通：完成评估，生存资源一般
- 长期：积累较多生存资源
- 稳定留存：生存资源充裕

**生存质量（纵轴）**
- 断裂：意义资源耗尽
- 功能性：维持基本连接
- 有连接：保持部分真实关系
- 高一致性：自我与行为统一

### 典型结局

| 类型 | 触发条件 | 文案示例 |
|------|---------|---------|
| 结构性斩杀 | 风险 ≥ 斩杀线 | 你并未失败。你只是承担了一个不被允许的位置 |
| 长期空洞 | 高生存 + 低意义 | 你被系统保留，但几乎不再被任何人记得 |
| 短暂真实 | 低生存 + 高意义 | 你没有走得太远，但你知道自己是谁 |
| 灰色特权 | 高生存 + 高意义 | 你活了下来，也知道代价是谁付的 |

## 游戏流程（15分钟完整体验）

```
主页 → 世界观介绍 → 身份选择 → 10个事件节点 → 双轴结算
 1分      1分         1分        10分           2分
```

## 技术栈

- Vue 3 + Vite + TypeScript
- Vue Router
- LocalStorage（记忆系统）
- 移动端优先（iOS Safari 优化）
- 无第三方 UI 库

## 设计理念

### 视觉风格
- **极简克制**：黑色背景 `#0f0f0f`，灰白文字
- **冷静叙事**：避免过度游戏化
- **压迫感**：通过文本节奏和时间延迟营造氛围

### 叙事原则
- **合规表述**：使用「系统判定」「关系破裂」「出局」等中性表达
- **无明确答案**：所有选择都合理，事后才能意识到接近斩杀线
- **结构性隐喻**：通过游戏机制传达社会学观察

### 核心问题
每个事件只问一件事：
> "你要安全，还是要真实？"
